# Praktikum Struktur Data

Repository ini berisi kumpulan tugas dan praktikum mata kuliah **Struktur Data** menggunakan bahasa pemrograman **Python**.

Repository ini digunakan untuk dokumentasi, latihan praktikum, dan pengumpulan tugas kuliah.

---

## Tugas Terbaru

### Advanced Sorter & ExprHeapSorter Visualizer

File tugas terbaru:

[advanced_sorter_visualizer.py](./python/advanced_sorter_visualizer.py)

Program ini merupakan visualisasi algoritma **Advanced Sorter** dan **ExprHeapSorter** untuk tugas Analisis & Desain Algoritma Bab 12 dan 13.

Program menggunakan:

- Python
- Tkinter
- Matplotlib

Cara menjalankan program:

```bash
python3 python/advanced_sorter_visualizer.py
```

Jika library `matplotlib` belum tersedia, install terlebih dahulu:

```bash
pip3 install matplotlib
```

## Cara Menjalankan File Python

Pastikan berada di folder repository:

```bash
cd STRUKTUR-DATA
```

Jalankan file Python dengan format:

```bash
python3 python/nama_file.py
```

Contoh:

```bash
python3 python/array.py
```

Untuk file yang memiliki spasi pada namanya, gunakan tanda kutip:

```bash
python3 "python/Bubble Sort dengan Analisis Langkah.py"
```
