# 🧠 Praktikum Struktur Data dengan Python
# 📚 Project Overview

Repository ini berisi kumpulan implementasi **Struktur Data dan Algoritma** menggunakan bahasa **Python** sebagai bagian dari praktikum mata kuliah Struktur Data.

Project mencakup:

- Implementasi struktur data dasar
- Simulasi algoritma
- Visualisasi sederhana
- Studi kasus nyata
- Optimasi pencarian & sorting
- Simulasi queue dan maze

Repository ini dibuat untuk membantu memahami konsep struktur data secara lebih praktis melalui implementasi langsung.

---

# 🎯 Tujuan Project

✅ Memahami konsep dasar struktur data  
✅ Mengimplementasikan algoritma menggunakan Python  
✅ Melatih problem solving dan logika pemrograman  
✅ Mensimulasikan kasus nyata menggunakan struktur data  
✅ Mengembangkan kemampuan analisis algoritma
